# Farmamagaracamartinici

Napravi mi onepage sajt koji ima pricu o farmi magaraca, mogucnost da se izmijeni svaka slika i svaki tekst na sajtu. Dakle napravi neki mini page builder za tu stranicu.
Napravi i chatbot koji odgovara na pitanja o upotrebi mlijeka od magaradia bazu informacija cemo mu uploadovati kroz neki word dokument sa cjelokupnim tekstom o mlijeku i njegovoj upotrebi iz kog ce  chatbot moci da vuce sve informacije i odgovara na pitanja posjetioca.
